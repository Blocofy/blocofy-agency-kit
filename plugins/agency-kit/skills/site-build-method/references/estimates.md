# Efor tahmini

Kitte yayımlanmış efor verisi yoktur: süreler ekibe, platforma ve müşterinin onay hızına
göre değişir. Kendi projelerinin retrosunda aşağıdaki tabloya satır ekle; aralıklar üç
veri noktasından sonra güvenilir sayılır.

| Proje tipi (mod, dil sayısı, sayfa ve koleksiyon ölçeği) | Faz grubu | Aktif süre | Not |
|---|---|---|---|
| | 0–3 Intake, keşif, kararlar, spec, plan | | |
| | 4–5 Prototip, bağımsız inceleme, v2 | | |
| | Revizyon döngüsü | | |
| | 8–9 Platform kurulumu ve tema | | |
| | 10–12 Yayın öncesi, yayın, devir | | |

İnsan onayı bekleme süresi bu tabloya girmez; ayrı tutulur.

## Planlama kuralları

- Takvimde **onay bekleme** ayrı satırdır; genellikle baskın kalemdir.
- İlk kez kullanılan platformda Faz 8–9'a %50 tampon ekle (platform hataları).
- Yapay zekâ ile üretilen video imza öğesi ayrı iş kalemi olarak fiyatlanır (üretim + kurgu + performans).
- Çok dilli sitede her ek dil: içerik onayı + eşdeğerlik + hreflang için Faz 6 ve 9'a ek süre.
