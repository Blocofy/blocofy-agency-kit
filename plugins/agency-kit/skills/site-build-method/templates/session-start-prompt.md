# Oturum başlatma istemi

## Yeni proje

```
Yeni müşteri sitesi: <proje kısa adı>.
Kaynaklar: <katalog PDF / marka kılavuzu / mevcut site URL / Excel / yok>.
Diller: <tr, en>. Hedef platform: <Blocofy / karar verilmedi>.
site-build-method skill'ini kullan. Faz 0'dan başla: STATE.md, decisions.md ve
open-questions.md'yi aç, intake sorularını sor. Mod kararını Faz 2'de benimle ver.
Her fazın sonunda kapı kanıtını göster ve onay iste.
```

## Devam

```
site-build-method ile devam et. STATE.md'yi oku, kapısı kapanmamış ilk fazı ve
sıradaki adımı söyle, bekleyen onayları listele. Konuşma geçmişine değil dosyalara dayan.
```

## Revizyon (dondurmadan sonra)

```
Revizyon talebi: templates/revision-request.md biçiminde <ekler>.
Önce incele ve etki analizini çıkar, seçenekleri görsel taslakla göster, onayımı bekle.
```
